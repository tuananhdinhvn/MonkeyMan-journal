Đây là bài viết mẫu. Bạn có thể xóa file này và thêm file `.mdx` mới trong
`content/posts/` để tạo bài viết — không cần database, không cần CMS.

## Viết Markdown bình thường

- Hỗ trợ **in đậm**, *in nghiêng*
- Hỗ trợ code block, list, ảnh...

Khi build, Next.js sẽ tạo sẵn (static generate) từng trang bài viết — tải cực
nhanh vì không cần gọi server hay database lúc người dùng truy cập.
