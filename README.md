# monkey-web

Personal portfolio & blog — Next.js + TypeScript + Tailwind, MDX blog content, no backend/database required.

## Bắt đầu

```bash
npm install
npm run dev
```

Mở http://localhost:3000

## Dùng Claude Code

```bash
claude
```

Claude Code sẽ đọc `CLAUDE.md` để hiểu quy ước và cấu trúc dự án.

## Deploy

Đẩy code lên GitHub rồi import vào [vercel.com](https://vercel.com) — build và deploy tự động, không cần cấu hình thêm.
